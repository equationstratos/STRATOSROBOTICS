ASIMOV

Robot humanoïde open source par Menlo Research

Menlo Research / Asimov Inc.
Sources

Site officiel : https://asimov.inc/
GitHub (open source complet) : https://github.com/asimovinc/asimov-1
Menlo Research : https://menlo.ai/asimov-1

Médias

Voir les vidéos et démos sur le site officiel et le GitHub du projet.

Spécifications

- Hauteur : 1,20 m
- Poids : 35 kg
- Degrés de liberté : 25 actionnés + 2 orteils passifs (compliant passive toes)
- Couple pic : jusqu'à 120 Nm
- Capteurs : caméra monocular 2MP, array de microphones, IMU, speaker
- Compute : Raspberry Pi 5 + Radxa CM5
- Matériaux : aluminium 7075 + nylon MJF PA12
- Licence : CERN-OHL-S-2.0 (hardware) + GPL-2.0 (software)

fichiers 3d / BOM

CAO complète, nomenclature (BOM), modèle MuJoCo et firmware disponibles gratuitement sur GitHub. Kit DIY disponible (précommande ~15 000 $).

Électronique

Bus CAN, contrôle temps réel, power distribution board. Tout documenté open source.

Assemblage

Manuel d'assemblage complet fourni. Environ 50-100 heures de build. Compatible self-sourcing ou kit.

Programmation

Firmware open source, simulation MuJoCo, support pour training locomotion et whole-body control. Idéal pour chercheurs et makers.

Coûts et délais

Kit DIY cible ~15 000 USD. Self-build possible via BOM. TCO annuel visé < 30 000 $. Livraison kit été 2026.

SYNTHESE

Asimov v1 est un robot humanoïde entièrement open source conçu par Menlo Research. Il vise à démocratiser la robotique humanoïde en fournissant plans, code, simulation et possibilité de construction DIY. Parfait pour le répertoire STRATOS ROBOTICS qui concentre les meilleurs projets open source.

Version la plus récente et sources : GitHub Asimov et asimov.inc

AMÉLIORATIONS POSSIBLES

Intégration avec les stacks IA de STRATOS, ajouts de capteurs, customisation esthétique, contributions au firmware de locomotion.

Compatibilité avec les outils existants du repo (Arduino, Raspberry, etc.) et extensions pour missions écologiques / humanitaires.
