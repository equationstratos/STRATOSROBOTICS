Drone open source de classe DJI Tello EDU — matériel, firmware, SDK et simulation

STRATOS ROBOTICS
AIR
Description

Un drone de classe DJI Tello EDU entièrement ouvert : la carte KiCad se commande assemblée chez JLCPCB, le châssis est un modèle OpenSCAD imprimable, le firmware de vol tourne sur un ESP32-P4 (vol, caméra, encodeur H.264 matériel) épaulé d'un ESP32-C6 pour le Wi-Fi 6.

L'interface de programmation est compatible au fil avec le SDK Tello 2.0, vidéo comprise : djitellopy fonctionne sans modification. Une simulation Gazebo Harmonic complète parle exactement le même protocole que le drone réel : les scripts de mission se testent au simulateur, puis tournent tels quels sur la machine.

Le dépôt abrite aussi les modèles Stratos3 et TinyHoop MK1, avec leurs CAO, leurs firmwares et leurs visualiseurs.

Caractéristiques
  • Masse ~92 g, empattement 118 mm, moteurs brossés 8520, hélices compatibles Tello
  • ESP32-P4 (vol + caméra) + ESP32-C6 (Wi-Fi 6)
  • Capteurs ICM-42688-P, SPL06-001, VL53L1X, PMW3901
  • Caméra OV5647 5 MP MIPI-CSI, H.264 matériel 720p30 au format Tello, extension 1080p30
  • SDK Tello 2.0 compatible (UDP 8889 / 8890 / 11111) + extensions
  • Vols en essaim, réels comme simulés
  • Simulation Gazebo Harmonic exécutant le même code de vol
