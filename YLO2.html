YLO2

Banc cinématique 3D et simulateur Python du quadrupède YLO-2

STRATOS ROBOTICS
GROUND
Description

Visualiseur 3D interactif et simulateur du quadrupède YLO-2 de Vincent Foucault (elpimous/ylo-2) : la machine est affichée avec ses vrais maillages, montée sur la chaîne articulaire de son URDF.

Elle s'anime soit par un générateur d'allures directement dans le navigateur, soit par des scripts Python : salto arrière, montée d'escalier, roues motrices, cabrage, tenue sur deux roues.

Le projet tient en trois pièces : le visualiseur (index.html), le convertisseur qui transforme les .dae/.stl du dépôt d'origine en paquet binaire compact, et le paquet Python ylo2-sim — cinématique, allures, bus CAN et trajectoires.

Le robot est bâti autour d'actionneurs moteus (mjbots), dans la lignée du MIT Mini Cheetah.

Caractéristiques
  • Vrais maillages du dépôt d'origine, montés sur la chaîne articulaire URDF
  • Générateur d'allures navigateur + télémétrie + éditeur de matières
  • Paquet Python ylo2-sim : cinématique, allures, bus CAN, trajectoires
  • Convertisseur tools/convert_meshes.py : .dae/.stl vers paquet binaire compact
  • Actionneurs moteus (mjbots), architecture MIT Mini Cheetah
